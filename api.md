# typeship — MCP reference

API version 1.0.0. Package version 0.9.1. Generated by typeship; regenerate rather than editing.

This package exposes `search_docs`, `read_docs`, and `execute`. Find an operation, read its input schema, then pass its name and arguments to `execute`. The operation names below are not directly callable tools in this mode. Destructive operations require `confirm: true`.

Tool arguments use API field names. Results use MCP content blocks; JSON objects also include `structuredContent` when available. A failed call has `isError: true` and a JSON error with `code` and `next_steps`. Input validation runs before the API request.

Event streams are not MCP tools. File uploads require a locally launched server. Read-only mode and tool filters can restrict the available operations; use the connected server's discovery response to check its active surface.

For complete input and output schemas, use [`api.json`](./api.json), the machine-readable companion to this reference.

## generate

### `generate_run`

Generate one Target from a Definition

`POST /generate`

Safety: **write** · Authentication: **optional**

Stateless generation: nothing is stored. Returns the full generated
package as files. Works without an API key: anonymous calls generate
the first 25 operations, rate limited per IP address, and the
response's `limits` object says what was held back and where to lift
it; anonymous calls from a Definition URL also carry `claim.url`, a link
that turns the run into a project once a person signs in. With a key, the free plan generates the first 25 operations and
paid plans generate the complete Definition. A present but invalid key is a
401, not a downgrade to anonymous.
